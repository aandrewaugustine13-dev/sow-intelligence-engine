# AI Agent Directives

**STRICT RESTRICTION:** AI coding agents and automated systems are strictly forbidden from modifying database schemas, migrations, or Row-Level Security (RLS) policies without explicit human approval.

1. Do NOT write, run, or modify SQL migration files.
2. Do NOT change Supabase configuration files related to the database schema.
3. Do NOT edit Row-Level Security (RLS) rules directly.
4. Always request permission from the user before executing any actions that would alter the database schema or its security model.
